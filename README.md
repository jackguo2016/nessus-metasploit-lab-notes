# CSCI 6531 · Vulnerability Scanning Lab

This computer security coursework report documents a vulnerability assessment of **Metasploitable**, a deliberately vulnerable virtual machine used for training. The lab connects automated scan findings with a controlled test of whether one vulnerability can be exploited.

## What the report covers

1. **Scan the lab VM with Nessus.** Record the scan results and the operating system that Nessus identifies.
2. **Validate a finding with Metasploit.** Document the attempt to exploit a vulnerability and the resulting access to the lab VM.
3. **Capture evidence.** The report uses screenshots to show the scan output, operating-system identification, and exploitation steps.

## Read the report

Open or download [`HW5submit.docx`](HW5submit.docx) to see the screenshots and submission notes. This repository contains the lab report. The virtual machine, scanner, and lab setup are separate from the submission.
